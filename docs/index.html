TPS View is a free, open-source app for building geometric morphometrics datasets. Open your images, place landmarks, set the scale, and save a clean .tps file ready for analysis, on Mac, Windows or Linux.

From images to an analysis-ready dataset

Everything you need to digitize hundreds of specimens, in one place.

📍

Landmarks

Click to place, drag to adjust, and mark landmarks as missing. Undo works without limit, and a magnifier helps you place points precisely.

📏

Scale tool & scale table

Click both ends of a ruler to set SCALE. Every specimen's scale is listed in one table, where you can edit values or apply them in bulk.

🖼️

Choose the exact image

Pick which image belongs to each specimen. Windows paths like C:\…\img.jpg are found automatically, and missing images can be relinked from a folder.

🗂️

Build from images

Start a new TPS file from a folder of photos, or drop more images onto the window to add specimens.

✅

Dataset check

Flags inconsistent landmark counts, missing scales or images, and duplicate IDs before you run your analysis.

📤

CSV export

Export coordinates in pixels or real units (scaled by SCALE), ready for R, Python or Excel.

Your files stay standard

TPS View reads and writes the standard TPS format: whole-pixel coordinates measured from the bottom-left corner, and SCALE in units per pixel. Your existing files open as they are, and the files you save work in the tools you already use for analysis:

MorphoJ geomorph (R) Morpho (R) PAST Python & Excel (CSV)

Install on macOS

TPS View is free, so it isn't signed with a paid Apple certificate. macOS asks you to approve it once.

  1. Download the .dmg, open it and drag TPS View to Applications.
  2. Open TPS View. When macOS warns it can't verify the developer, click Done.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway.

If macOS says the app “is damaged”, run this once in Terminal:

xattr -cr "/Applications/TPS View.app"
